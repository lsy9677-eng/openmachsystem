230MATCH 1.0.0 정식 배포 방법

1. 배포 전 현재 운영본 전체를 별도로 백업합니다.
2. 이 폴더 안의 index.html, assets, data 및 문서 파일을 사이트 루트에 업로드합니다.
3. 기존 /v3 폴더는 즉시 삭제하지 말고 최소 한 차례 실제 대회가 끝날 때까지 비상 복구용으로 보존합니다.
4. 배포 후 아래 주소에서 확인합니다.
   https://tennis230.pages.dev/?v=1000
5. 관리자 로그인 후 현재 대회와 부서를 확인하고, 전체 JSON 백업을 한 번 저장합니다.

시합 당일 Firebase 운영 원칙
- 관리자·진행자 권한은 실제 입력 담당자에게만 부여합니다.
- 일반 선수·관람자는 읽기 전용으로 유지합니다.
- Firebase 오류가 발생해도 로컬 운영을 계속하고 반복 업로드를 누르지 않습니다.
- 네트워크 회복 후 최신 상태 한 건이 동기화되는지 확인합니다.
- 예선 확정 전, 본선 추첨 전, 대회 종료 전에 전체 JSON 백업을 저장합니다.
