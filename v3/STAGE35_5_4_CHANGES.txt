230MATCH V3 Stage35.5.4
조회 사용자 Firebase 부하 제한

기준본
- Stage35.5.3 로컬 우선·Firebase 부하 보호
- Stage35.5.1/35.5.2 부서별 동기화·접속자 표시 기능은 포함하지 않음

변경 내용
1. 관리자·진행자는 기존 Firebase 실시간 수신 유지
2. 일반 읽기 전용 사용자는 onSnapshot 실시간 리스너를 사용하지 않음
3. 읽기 전용 사용자는 최대 45초 간격으로 최신 상태 조회
4. 브라우저 탭이 백그라운드이면 Firebase 조회 완전 중지
5. 화면으로 돌아오면 즉시 1회 조회 후 45초 간격 재개
6. 수동 클라우드 불러오기 기능 유지
7. Firebase 오류가 나도 로컬 화면과 경기 운영은 계속 유지
8. 진행자 쓰기 합치기·6초 최소 간격·회로 차단 기능 유지

부하 원칙
- 진행자 수는 필요한 최소 인원으로 제한
- 참가자·일반 조회자는 실시간 읽기 대신 제한 조회 사용
- Firebase 장애를 완전히 방지할 수는 없으나, 접속자 수와 경기 변경 횟수가 동시에 증가할 때 읽기 폭증을 제한함
