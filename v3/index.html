체크리스트를 확인하세요.

    

    

      
정상 운영 순서
  1. 관리자 로그인 후 복구점을 저장합니다.
  2. 참가자 연락처와 후보·취소팀을 정리합니다.
  3. 예선 조와 코트를 확정하고 참가자에게 안내합니다.
  4. 경기 결과를 입력하면 순위와 본선 진출팀을 확인합니다.
  5. 본선 추첨 후 빈코트 → 대기1 → 공용대기 순서로 운영합니다.
  6. 자동 문자 승인창에서 대상·코트·내용을 확인한 뒤 발송합니다.
  7. 결승 종료 후 결과를 보관하고 전체 백업을 내려받습니다.

      
결과를 잘못 입력했을 때
  1. 추가 결과 입력을 잠시 멈춥니다.
  2. 운영 로그에서 잘못된 작업 시간을 확인합니다.
  3. 해당 경기의 결과 수정 기능으로 먼저 바로잡습니다.
  4. 본선 진출·다음 라운드까지 잘못 반영됐다면 가장 최근 정상 복구점을 사용합니다.
  5. 복구 후 대진표와 코트 대기열을 다시 확인합니다.

      
인터넷·Firebase 장애
  1. 새로고침을 반복하지 말고 현재 화면을 유지합니다.
  2. 휴대전화 데이터 또는 다른 와이파이로 연결을 확인합니다.
  3. 로컬 상태가 보이면 결과 입력을 최소화하고 종이 또는 메모로 병행합니다.
  4. 연결 복구 후 운영 점검과 오류 진단을 실행합니다.
  5. 정상 동기화가 확인되기 전 전체 초기화나 복구를 실행하지 않습니다.

      
문자 발송 장애
  1. 문자 센터에서 수신번호와 발송 문구를 확인합니다.
  2. 알리고 실패 시 휴대전화 문자앱 열기를 사용합니다.
  3. PC에서는 번호와 문구 복사 기능으로 대체합니다.
  4. 같은 경기 문자를 다시 보낼 때 중복 발송 여부를 먼저 확인합니다.
  5. 푸시 수신자는 문자 대체 대상에서 제외됐는지 확인합니다.

      
코트·대기열이 꼬였을 때
  1. 진행 중인 경기는 먼저 종료하거나 현재 상태를 기록합니다.
  2. 잘못 이동한 카드를 관리자 이동 버튼으로 원래 위치에 되돌립니다.
  3. 각 코트에는 현재 경기 1개와 대기1 1개만 유지합니다.
  4. 나머지 경기는 구장 공용대기로 이동시킵니다.
  5. 대진표의 다음 경기 참가팀과 대기 카드가 일치하는지 점검합니다.

      
브라우저 화면 이상·캐시 문제
  1. 먼저 주소의 버전 번호가 최신인지 확인합니다.
  2. PC는 Ctrl+Shift+R, 휴대전화는 브라우저를 완전히 닫고 다시 실행합니다.
  3. 그래도 이상하면 오류 진단 보고서를 저장합니다.
  4. 데이터가 정상이라면 캐시 삭제 후 다시 접속합니다.
  5. 복구 전에는 반드시 현재 상태 JSON 또는 복구점을 저장합니다.
