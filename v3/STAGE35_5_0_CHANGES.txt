230MATCH V3 Stage 35.5.0
동시 접속 충돌 방지

기준본
- Stage35.4.2

확인 결과
- 운영 점검, 정합성 검사, 격리 리허설, 복구점, 전체 JSON 백업, 종료 아카이브가 이미 존재함
- 중복 검사·복원 기능은 추가하지 않음

변경 사항
1. Firebase 대회방 상태에 revision/baseRevision 추가
2. 저장 직전 Firestore transaction으로 서버 revision 재확인
3. 다른 진행자가 먼저 저장한 경우 자동 덮어쓰기 중단
4. 실시간 수신 중 로컬 미저장 변경과 원격 변경이 겹치면 충돌 모달 표시
5. 충돌 해결 선택
   - 클라우드 상태 받기
   - 현재 기기 상태로 강제 덮어쓰기
   - 나중에 결정
6. 동기화 상태에 revision과 마지막 수정자 표시
7. 충돌 중에는 자동 저장과 수동 일반 푸시 차단
8. 기존 로컬 자동 저장, 복구점, 백업, 기록 보존 기능 유지

주의
- 강제 덮어쓰기는 다른 진행자의 변경을 삭제할 수 있으므로 마지막 수단으로만 사용
