STAGE 32.5.2 · MEMBER PROFILE, SMS TARGET & DELETE REQUEST
- 관리자 문자 수신대상: 대표전화만 / 두 선수 모두 선택
- 같은 전화번호를 두 선수에게 입력 가능하며 문자 발송 시 같은 번호는 1건으로 정리
- 로그인 회원 프로필의 이름·전화·클럽을 참가신청 선수1에 자동 입력
- 참가신청 후 회원 프로필 기본정보 자동 갱신
- 로그인한 신청자는 승인 대기 신청 수정 가능
- 참가신청 삭제는 삭제 요청 후 관리자 최종 삭제
- 회원 프로필 전화번호와 참가팀 연락처가 일치하면 내 경기 자동 표시
